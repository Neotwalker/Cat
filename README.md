# Cursor Cat

Экспериментальный hero-блок с интерактивным котом, который следит за курсором.

## Что уже работает

- глаза реагируют на курсор быстрее головы;
- голова плавно доворачивается с инерцией;
- уши двигаются отдельно;
- случайное моргание;
- idle-анимация без движения мыши;
- мобильный fallback;
- поддержка `prefers-reduced-motion`;
- адаптивная верстка без фреймворков.

## Запуск

Проект статический. Достаточно открыть `index.html` в браузере или запустить любой локальный HTTP-сервер.

Например:

```bash
python3 -m http.server 8080
```

Затем открыть `http://localhost:8080`.

## Следующие итерации

1. Заменить CSS-персонажа на финальный визуальный asset кота.
2. Увеличить диапазон естественных поворотов головы.
3. Добавить микродвижения морды и более натуральные веки.
4. При необходимости перейти к sprite-based или rigged 3D версии, не меняя базовую логику реакции на курсор.
