# Cursor Cat — Three.js skeletal prototype

Интерактивный hero-блок с кастомным 3D-котом. Текущий этап — перенос удачной CSS-анимации на настоящий bone rig в Three.js.

## Что уже работает

- Three.js renderer внутри hero;
- bone hierarchy: `ROOT → BODY → CHEST / NECK → HEAD`;
- отдельные кости глаз и ушей;
- цепочка хвоста `TAIL_01 → TAIL_TIP`;
- глаза реагируют быстрее головы;
- голова и шея движутся с разной инерцией;
- уши имеют независимую реакцию;
- хвост живёт отдельной синусоидальной анимацией;
- дыхание корпуса;
- idle-поведение без движения мыши;
- реакция на клик / тап;
- адаптивный canvas;
- поддержка `pointer: coarse` и `prefers-reduced-motion`;
- debug-кнопка «Показать скелет».

## Важно

Текущая геометрия намеренно примитивная. Это технический skeletal prototype.

Следующий этап — заменить примитивы на собственную 2.5D/3D-геометрию, построенную под выбранный референс кота.

Готовые сторонние модели не используем.

## Ветки

- `main` — текущая 2.5D/3D разработка;
- `css-prototype` — сохранённая рабочая CSS-версия.

## Запуск

Проект статический, но из-за ES modules его нужно открывать через HTTP-сервер:

```bash
python3 -m http.server 8080
```

Затем открыть:

```
http://localhost:8080
```
